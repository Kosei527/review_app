# 知識辞書アプリ
AIに聞いた知識を言語化して定着するツール

## なぜ作ったのか
大学生活を送る中で、AIを使ってプログラミングを書く機会がとても多く、その得た知識のほとんどが読むだけで満足し、自分のものにはなっていなかった。なのでその問題を解決するために、AIに聞いた知識を自分の言葉で作るツールが欲しいと感じた。
このアプリでは、学んだ工程を「おさらい・なぜ・一般化・保存」の4工程で自分の言葉で整理して保存することで、読むだけで終わらず、定着させることを狙いとしている。

## 主な機能
- 知識の保存(おさらい・なぜ・一般化・分野の4項目)
- 保存した知識の一覧表示
- 分野による検索・絞り込み

## 使用技術
- FastAPI(Python)...バックエンド
- SQLite...データベース
- Jinja2...テンプレート(HTML作成)
- HTML/CSS...フロントエンド
- Render...デプロイ(ホスティング)

## 工夫した点
### 技術選定
まず最初に使用する技術については、現在大学でPythonを学んでいること、新要素を詰め込みすぎないということを理由に、FastAPIを選んだ。
### SQLite3の使用
ライブラリに頼らず、sqlite3を自分で書いた。そうすることで今まで簡略化されてきたDBの仕組みを順を追って理解することができた。
### MVPの完成
また当初の予定であった、一般化の部分を最後AIが添削する部分については、まずは基礎となるMVPを作成してから追加するというのは正しかった。そうすることで全体を通して自分が何をするべきなのかを見失うことなくMVP完成まで持ってこれた。
